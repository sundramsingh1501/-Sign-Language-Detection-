#  Sign Language Detection System (Real-Time)

A real-time **Sign Language Detection System** built using **OpenCV and Deep Learning (CNN)**.  
The system detects hand gestures from a webcam feed, isolates the hand region using
computer vision techniques, and classifies gestures such as **OKAY**, **THANK YOU**, and **HELP ME**.

This project is designed to be **fast, reliable, and compatible with Python 3.13**.

---

##  Features

- Real-time hand detection using OpenCV
- Background removal using skin-color segmentation
- CNN-based gesture classification
- Low-latency predictions (no lag)
- Works without MediaPipe (Python 3.13 compatible)
- Clean and modular code structure
